# Doctor Marketing — sitio web

Sitio bilingüe (ES/EN) de Doctor Marketing y sus unidades: Doctor Media, Doctor People y Doctor Business.

## Estructura
- `index.html` — todo el sitio en un solo archivo (estilos, fuente EOne incrustada y scripts). Las pestañas se navegan con `#inicio`, `#nosotros`, `#media`, `#people`, `#business`, `#terminos` y `#contacto`.
- `logos/` — logos en PNG para fondo negro.

## Publicar con GitHub Pages
1. En el repositorio: **Settings → Pages**.
2. En *Source* elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. Guarda. En uno o dos minutos el sitio queda en `https://<usuario>.github.io/<repositorio>/`.
4. Para usar tu dominio (por ejemplo drmarketing.pro), escríbelo en *Custom domain* y apunta el DNS a GitHub Pages.
